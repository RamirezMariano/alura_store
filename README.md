Challenge Alura Store - Análisis de Datos

Análisis exploratorio de datos realizado como parte del Challenge de Data Science de Alura LATAM.
El objetivo del proyecto es analizar el rendimiento de cuatro tiendas de la cadena Alura Store para determinar cuál debería vender el Sr. Juan con el fin de invertir en un nuevo emprendimiento.

Objetivo del proyecto

Evaluar el desempeño de las cuatro tiendas utilizando datos de ventas, reseñas de clientes y costos de envío para identificar la tienda con menor rendimiento dentro de la cadena.

El análisis se centra en indicadores clave como:

Ingresos totales por tienda

Ventas por categoría de producto

Valoración promedio de clientes

Productos más vendidos y menos vendidos

Costo promedio de envío

Tecnologías utilizadas

Python

Pandas

Matplotlib

Google Colab

GitHub

Análisis realizados
Ingresos por tienda

Se calcularon los ingresos totales de cada tienda sumando los valores de la columna Precio para identificar cuál genera mayor volumen de ventas.

Ventas por categoría

Se agruparon las ventas por categoría de producto para analizar cuáles son las categorías más populares en cada tienda.

Valoración promedio de clientes

Se calculó la media de las calificaciones de los clientes para evaluar el nivel de satisfacción en cada tienda.

Productos más vendidos

Se identificaron los productos con mayor y menor cantidad de ventas para entender el comportamiento del catálogo.

Costo promedio de envío

Se analizó el costo promedio de envío pagado por los clientes en cada tienda.

Visualización de datos

Durante el análisis se generaron diferentes gráficos utilizando Matplotlib, incluyendo:

Gráficos de barras para comparar ingresos entre tiendas

Distribución de ventas por categoría

Comparación de valoraciones promedio

Costo de envío promedio por tienda

Estas visualizaciones permiten identificar patrones y diferencias entre las tiendas de forma clara.

Conclusión

Luego de analizar los diferentes indicadores, se concluye que la Tienda 4 presenta el menor rendimiento general dentro de la cadena.

Aunque las valoraciones de los clientes son similares entre las tiendas, la Tienda 4 muestra:

Los ingresos totales más bajos

Un volumen de ventas menor

Menor contribución al rendimiento general del negocio

Por este motivo, se recomienda que el Sr. Juan considere vender la Tienda 4 y utilizar los recursos obtenidos para invertir en un nuevo emprendimiento.
