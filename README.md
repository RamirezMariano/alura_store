Challenge Alura Store - Análisis de Datos

Este proyecto analiza el desempeño de las cuatro tiendas de Alura Store
utilizando Python, Pandas y Matplotlib.

Se evaluaron los siguientes indicadores:
- Ingresos totales
- Ventas por categoría
- Valoración promedio de clientes
- Productos más vendidos
- Costo de envío promedio

Conclusión:
El análisis indica que la Tienda 4 presenta el menor desempeño
en términos de ingresos y volumen de ventas, por lo que se recomienda
su venta para permitir la inversión en un nuevo emprendimiento.
